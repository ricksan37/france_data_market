What appears, what disappears

02: COMPENSATION

Median advertised salary

Computed only on offers showing a plausible annual salary, and by distinct listing. An employer publishing the same position in twenty-four communes therefore counts only once in the median. The median also resists outliers, unlike the mean.

France Data Market Observatory. dbt and DuckDB pipeline, SIRENE enrichment via the Company Search API (DINUM), skill extraction via local LLM (Ollama, mistral-nemo). Report regenerated on every pipeline run. The Technologies and Domains sections require a local run with LLM extraction, absent from the CI runner (CI_WITHOUT_EXTRACTION): they stay empty on every automated report. Unless stated otherwise, measurements cover distinct listings rather than offers: the same listing published in several cities gets one identifier per city, and would otherwise count that many times. The Geography section is the exception, for the reason stated under its chart.
