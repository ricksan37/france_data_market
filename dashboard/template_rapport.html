Observatoire du Marché Data France. Pipeline dbt et DuckDB, enrichissement SIRENE via l'API Recherche d'entreprises (DINUM), extraction de compétences par LLM local (Ollama, mistral-nemo). Rapport régénéré à chaque exécution du pipeline. Les sections Technologies et Domaines exigent un run local avec extraction LLM, absente du runner CI (CI_SANS_EXTRACTION) : elles restent vides sur tout rapport automatisé.
